Професійні консультації

Наші фахівці допоможуть підібрати оптимальні товари для ваших потреб та відповісти на всі запитання.

Асортимент магазину GOODSYA UA:

  • Все для кухні — кухонне приладдя, посуд, електроприлади, аксесуари для приготування їжі.
  • Красота та здоров'я — бьюти-гаджети, догляд за шкірою, прилади для догляду за волоссям, масажне обладнання.
  • Товари для дому та саду — предмети інтер'єру, садовий інвентар, організатори, побутова хімія.
  • Освітлення — LED лампи, фонарики, декоративне освітлення, аварійні ліхтарі.
  • Годинники та гаджети — смарт-годинники, фітнес-браслети, розумні годинники для всієї родини.
  • Аудіотехніка — Bluetooth колонки, навушники, музичні центри, портативні акустичні системи.
  • Електроніка — корисні гаджети, зарядні пристрої, техніка для дому, розумні пристрої.
  • Аксесуари — чохли для гаджетів, кабелі, підставки, інші корисні дрібниці для комфорту.

  • 5.1. На всі товари поширюється гарантія виробника. Термін гарантії вказаний у картці товару або в супровідних документах.

    • Обміняти товар або повернути кошти клієнт може лише в день отримання замовлення.

    • Офіційну гарантію надає лише виробник у Китаї, а відправляти товар до Китаї на ремонт немає сенсу.

    • Ми підтвердимо повернення та надамо дані для відправлення товару.
    • Клієнт відправляє товар, оплачуючи доставку самостійно.
